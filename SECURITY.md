# Security reporting

This is an early source preview with no production security guarantee or response
SLA. Model-generated Python and desktop operations run with the user's permissions.

For a suspected vulnerability, use this repository's **Security → Report a
vulnerability** private reporting flow when enabled. Do not place credentials,
private transcripts, browser profiles, or exploit-sensitive material in public
issues. If the private reporting control is unavailable, open a minimal issue
requesting a private contact without including sensitive details.

Include the affected version/commit, operating system, minimal reproduction using
synthetic data, impact, and any proposed mitigation. Ordinary usability bugs can
go through GitHub Issues with redacted diagnostics.
